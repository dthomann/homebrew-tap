# homebrew-tap

Homebrew tap for [MacViewPro](https://www.macviewpro.com), a free native macOS image viewer.

Installers are downloaded from [GitHub Releases](https://github.com/dthomann/macviewpro/releases) (same notarized DMG as the website).

## Install

```bash
brew tap dthomann/tap
brew install --cask macviewpro
```

One-shot:

```bash
brew install --cask dthomann/tap/macviewpro
```

## Upgrade

```bash
brew upgrade --cask macviewpro
```
